## 수정 기록

> 버전: `월요병진단서_v1.html`(2-2에서 고른 원본) → `v2` → `v3` → `v4` → `v5`(사용자 테스트 피드백 반영) → 최종본 `월요병_진단서.html`(v5와 같은 내용). 수정할 때마다 그 문제 하나만 고치고, 고친 부분과 원래 되던 기능을 다시 테스트했습니다.
>
> 원래 되던 기능 재확인 항목(매 버전): 0% / 19%(1·3번) / 20%(2·5번) / 87%(9번만 빼고) / 100%의 지수와 진단명, 빈 이름 안내, 이미지로 저장, 다시 진단하기(체크만 풀리고 이름은 남음), 375px 폭에서 오른쪽 잘림 없음

### 수정 기록 1 (v1 → v2)
- 발견한 문제: 휴대폰 폭(375px)에서 증상 3개를 체크하고 이름은 비운 채 맨 아래 '진단하기'를 눌렀더니(테스트 내용), '환자 이름을 입력해 주세요.' 안내가 보일 줄 알았는데(예상 결과) 화면이 맨 위 이름 칸으로 올라가기만 하고 안내 문구는 화면에 보이지 않았습니다. 안내 문구는 화면 밖, 맨 아래 '진단하기' 버튼 밑에 있었습니다(실제 결과).
- AI에게 전달한 요청: "휴대폰 폭에서 이름을 비우고 맨 아래 '진단하기'를 누르면 화면이 이름 칸으로 올라가는데, '환자 이름을 입력해 주세요.' 안내는 맨 아래에 있어서 안 보여. 이름 칸이 보일 때 안내도 같이 보이게 이 부분만 고치고, 고친 HTML 전체를 줘."
- 수정 후 테스트 결과: 같은 방법으로 다시 해 보니 이름 칸 바로 아래에 빨간 안내 문구가 나와 한 화면에 같이 보였습니다. 원래 되던 기능 재확인 항목도 모두 이전과 같았습니다. 
- 수정 이유: 안내가 안 보이면 사용자는 왜 화면이 위로 튀었는지 알 수 없어서, 진단이 안 되는 줄 알고 '진단하기'를 여러 번 누르거나 페이지가 고장 났다고 생각합니다.

### 수정 기록 2 (v2 → v3)
- 발견한 문제: 휴대폰에서 이름 칸에 '장수인'을 쓰고 키보드의 '완료'(엔터)를 눌렀더니(테스트 내용), 이름만 입력되고 체크리스트로 넘어갈 줄 알았는데(예상 결과) 아무것도 체크하지 않은 채로 바로 '0% 월요병 음성' 진단서가 나왔습니다(실제 결과).
- AI에게 전달한 요청: "이름을 입력하고 휴대폰 키보드에서 엔터를 누르면, 체크를 하나도 안 했는데 바로 0% 진단서가 나와. 엔터를 누르면 진단하지 말고 체크리스트로 넘어가게 이 부분만 고치고, 고친 HTML 전체를 줘."
- 수정 후 테스트 결과: 같은 방법으로 다시 해 보니 진단서는 나오지 않고 1번 문항으로 넘어갔습니다. 휴대폰 키보드 버튼도 '다음'으로 바뀌었습니다. '진단하기' 버튼으로 진단하는 것과 원래 되던 기능 재확인 항목은 이전과 같았습니다.
- 수정 이유: 휴대폰에서는 이름을 쓴 뒤 '완료'를 누르는 게 자연스러운 행동이라, 사용자가 증상을 고르기도 전에 0% 진단서를 받고 당황하거나, 그 결과를 진짜 결과로 오해할 수 있습니다.

### 수정 기록 3 (v3 → v4)
- 발견한 문제: 2·3·5번을 체크하고 진단해 31%가 나온 뒤, 9·10번을 더 체크하고 '진단하기'는 다시 누르지 않은 채 '이미지로 저장'을 눌렀더니(테스트 내용), 바뀐 체크가 반영될 줄 알았는데(예상 결과) 화면의 진단서와 저장한 이미지 모두 31% 그대로였습니다. 이름을 바꿔도 진단서의 환자명은 예전 이름 그대로였습니다(실제 결과).
- AI에게 전달한 요청: "진단서가 나온 뒤 체크를 더 하거나 이름을 바꾸고 '진단하기'를 다시 안 누르면, 진단서와 저장한 이미지가 예전 결과 그대로야. 진단서가 보이는 동안 체크나 이름을 바꾸면 진단서도 바로 바뀌게 이 부분만 고치고, 고친 HTML 전체를 줘."
- 수정 후 테스트 결과: 같은 방법으로 다시 해 보니 9·10번을 체크하는 순간 진단서가 59%(10+11+10+13+15)와 '중등도 월요병'으로 바뀌었고, 이때 저장한 이미지도 59%였습니다. 이름을 바꾸면 환자명도 바로 바뀌었고, 이름을 모두 지우면 진단서가 사라지고 안내가 나왔습니다. 원래 되던 기능 재확인 항목도 이전과 같았습니다. 
- 수정 이유: 지금 체크와 다른 진단서가 저장되면, 친구들에게 공유한 이미지가 내가 고른 증상과 맞지 않게 됩니다. 사용자는 화면 결과가 옛날 것인지 알아차리기 어렵습니다.

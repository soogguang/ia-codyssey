# 영화 티어리스트 기획서

## 1. 누가 쓰나
- 나 혼자 내 컴퓨터에서 사용한다.
- 만든 결과는 친구들과 주변 사람들에게 공유한다.

## 2. 무엇을 하려고
- 내가 본 영화를 등급별로 나눈다.
- 나눈 결과를 PNG 이미지로 저장해 친구들에게 공유한다.

## 3. 화면과 동작
- 등급 칸은 위에서부터 S / A / B / C / F 다섯 개이다.
- 등급 칸마다 서로 다른 색을 쓴다. 구체적인 색은 만드는 사람에게 맡긴다.
- 전체 분위기는 딱딱하고 어두운 티어표가 아니라, 갈색·연두색 같은 포근하고 부드러운 '메론빵 감성'으로 한다.
- 등급 칸 아래에 "미분류" 칸이 있다.
- 처음 열면 영화 8편이 모두 미분류 칸에 있다.
- 영화는 포스터 이미지가 있고, 포스터 아래에 제목이 작게 적힌 카드로 보인다.
- 영화 카드를 클릭한 뒤 등급을 선택하면 그 등급 칸으로 옮겨진다.
- 파일을 닫았다가 다시 열어도 옮겨 둔 배치가 그대로 남아 있다.
- "초기화" 버튼을 누르면 모든 영화가 미분류 칸으로 돌아간다.
- "PNG로 저장" 버튼을 누르면 티어리스트가 PNG 이미지 파일로 저장된다.
  - PNG에는 맨 위에 제목 문구가 들어간다.
  - PNG에는 미분류 칸을 넣지 않고 S / A / B / C / F 등급 칸 5줄만 넣는다.

## 4. 필요한 자료
- 영화 8편 (추가·삭제 없이 고정): 기생충, 인터스텔라, 라라랜드,
  센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리
- 영화 8편의 포스터 이미지: 내가 직접 구해 준비하고, HTML 파일 안에 넣어 외부 파일 없이 열리게 한다.

## 5. 완성 기준
- 파일을 처음 열면 영화 8편이 모두 미분류 칸에 있고, 카드마다 포스터와 제목이 보인다.
- '기생충' 카드를 클릭하고 S를 선택하면 '기생충'이 S칸으로 옮겨진다.
- '기생충'을 S칸으로 옮긴 뒤 파일을 닫고 다시 열어도 '기생충'이 S칸에 있다.
- "초기화"를 누르면 모든 영화가 미분류 칸으로 돌아가고, 다시 열어도 미분류 칸에 있다.
- 영화 몇 편을 등급 칸에 옮긴 뒤 "PNG로 저장"을 누르면 PNG 파일이 내려받아진다.
- 내려받은 PNG를 열면 맨 위에 제목이 있고, 화면에서 옮긴 등급 배치가 그대로 보이며, 미분류 칸은 보이지 않는다. 등급 칸은 S / A / B / C / F 5줄이다.

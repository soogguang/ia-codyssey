## 두 AI 비교

- AI A (서비스·모델 이름): Claude, claude-opus-5-5 → `월요병진단서_v1.html`
- AI B (서비스·모델 이름): ChatGPT, GPT-6.1 Sol (high) → 
- 동일한 기획서와 함께 전달한 요청: 기획서.md를 첨부하고 "기획서대로 HTML을 만들어 줘."와 함께 아래 조건을 전달했습니다.
  - HTML은 파일 1개로 구성한다. CSS와 필요한 JavaScript를 같은 파일에 포함하고, 평가자가 브라우저에서 열어 기획서의 필수 기능을 확인할 수 있도록 한다.
  - 로그인, API 키, 서버가 필요한 기능과 챗봇·AI 기능은 추가 기능으로 분류하고, 이번 제작 요청에서는 제외한다.
  - 사진·글·글꼴·라이브러리 등 외부 자료는 사용 권한을 확인한 뒤 활용한다. 사진은 로컬 파일 대신 https://로 시작하는 인터넷 주소로 삽입한다.

- 두 결과 모두 0%, 19%(1번+3번), 20%(2번+5번), 87%, 100%와 빈 이름 안내, 다시 진단하기, 375px 폭에서 오른쪽 잘림 없음은 똑같이 통과했습니다.
- 선택하지 않은 B는 초록색 '월요일 클리닉' 디자인이고, 넓은 화면에서 체크리스트가 2열로 나옵니다. 화면 비교는 `비교_진단하기직후_휴대폰_A왼쪽_B오른쪽.png`, `비교_저장한PNG_A왼쪽_B오른쪽.png`에 남겼습니다.
- 선택한 결과물과 근거: A(Claude)를 선택한다. 기획서에는 없지만 진단하기를 눌렀을 때 진단서 화면까지 자동으로 넘어가는 것이 편하다. 또한 진단서 이미지를 저장했을 때 '※ 재미로 보는 결과이며 실제 의학적 진단이 아닙니다.' 문구가 포함되어 있어서, 이미지를 받은 사람이 실제 의학적 진단이라고 오해하지 않을 수 있을 것 같아 좋았다.

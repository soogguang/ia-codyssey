# 민수 님께 드리는 피드백

잘된 점: 등급마다 색이 확실히 달라서(S 빨강, A 주황, B 초록, C 파랑) 어느 칸인지 바로 알 수 있었어요. 영화를 옮길 때마다 위에 '8편 중 3편 나눔'처럼 바뀌어서 얼마나 남았는지 한눈에 보였고, 카드를 누르고 등급 글자를 누르는 방식은 스크롤 없이도 편하게 옮길 수 있었어요. '처음으로'도 직접 추가한 영화까지 깔끔하게 지우고 처음 8편으로 잘 돌아갔어요.

고치면 좋을 점

1. 본 것: 영화 8편을 모두 나눈 뒤('8편 중 8편 나눔') 파일을 다시 열었더니 '8편 중 0편 나눔'으로 전부 미분류로 돌아갔어요.
   기준: 기획서의 '같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다'
   제안: 영화를 옮기거나 추가할 때마다 브라우저에 배치를 저장해 두고, 파일을 열 때 그 배치를 불러오면 좋겠어요.

2. 본 것: 브라우저 창을 휴대폰 폭만큼 좁혔더니 페이지 폭이 그대로라 오른쪽이 잘렸고, 옆으로 밀어서 볼 수도 없었어요.
   기준: 기획서의 '화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다'
   제안: 페이지 폭을 화면 크기에 맞춰 줄어들게 하고, 좁은 화면에서는 카드가 다음 줄로 내려가게 하면 좋겠어요.

3. 본 것: 제목 칸에 공백만 넣고 '추가'를 눌렀더니 글자 없는 빈 카드가 생기고 영화 수가 9편으로 늘었어요. 이 빈 카드는 '처음으로'를 누르기 전까지 지울 방법이 없었어요.
   기준: 기획서에는 없는 내용이지만, 쓰다가 실수로 눌렀을 때 불편했어요.
   제안: 제목이 비어 있으면 카드를 만들지 말고 "영화 제목을 입력해 주세요" 같은 안내를 보여 주면 좋겠어요.
